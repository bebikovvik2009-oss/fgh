# GEZA SERVICE — сайт

Открыть: `index.html` (двойной клик) или залить папку целиком на любой хостинг.

## Структура
- `index.html` — разметка всех экранов (главная, услуги, запись, адреса, отзывы, квитанции)
- `css/style.css` — все стили: тёмная тема, стеклянные рамки, кнопки, меню, анимации, адаптив
- `js/app.js` — вся логика: пиксельный фон и виньетка, анимации прокрутки, навигация,
  каталог услуг и цены, выпадающие меню брендов, запись, помощник, квитанции, карта
- `assets/img/hero.jpg` — фото на главной
- `assets/img/devices/` — карточки техники (телефон, ноутбук, планшет, консоль)
- `assets/img/services/<тип>/NN.jpg` — фото услуг, номер = порядок услуги в разделе
- `assets/icons/brands/` — логотипы брендов
- `assets/icons/social/` — иконки Telegram и MAX

## Заметки
- Шрифт Inter грузится с Google Fonts (нужен интернет).
- Помощник вне Claude работает в обычном режиме (быстрые ответы и запись, без ИИ).
- Карта 2ГИС показывается, когда сайт открыт с хостинга (http/https).
- Заменить фото: положите новый файл с тем же именем.
- Отзывы из 2ГИС подгружаются автоматически при открытии сайта с хостинга; если 2ГИС недоступен, показываются сохранённые.

## Сервер и Telegram-бот
- Пока сервер не подключён, записи уходят в Telegram напрямую (const TG в js/app.js).
- С сервером (папка server, инструкция там же): общее занятое время, записи в бот с кнопкой отмены,
  управление сайтом из бота — закрыть запись, цены, убрать время.
