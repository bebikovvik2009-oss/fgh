# Сервер сайта и бот управления — настройка (один раз, ~15 минут, бесплатно)

Сервер делает три вещи:
- занятое время пропадает у всех посетителей сайта, двойной записи не будет;
- новые записи приходят в Telegram (с кнопкой «Отменить запись»);
- из бота можно закрыть/открыть запись, поменять цены, убрать время, посмотреть записи.

## 1. Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный тариф).
2. **Хранилище:** Storage & Databases → KV → Create → имя `geza-db`.
3. **Сервер:** Compute → Workers & Pages → Create → Worker → «Hello World» → Deploy.
4. Edit code → удалите всё и вставьте содержимое файла `worker.js` → Deploy.
5. Worker → Settings → Bindings → Add → KV namespace:
   имя переменной `DB`, namespace `geza-db` → Save.
6. Worker → Settings → Variables and Secrets → Add (тип **Secret**):
   - `BOT_TOKEN` — токен бота от @BotFather
   - `PASSWORD` — слово для подключения, только латиница/цифры/_ (например `geza2026`)
   - `OWNER_ID` — (необязательно) ваш Telegram ID, например `7573906909` — этот человек получает доступ сразу
   → Deploy.

## 2. Связать бота с сервером
Откройте в браузере: `https://<адрес воркера>/setup?key=<PASSWORD>`
(адрес вида `https://geza.<ваше-имя>.workers.dev` виден на странице воркера).
Страница покажет «✅ Бот подключён», ссылку для владельца и адрес для сайта.

## 3. Сайт
В `js/app.js`:
- найдите `const ORDER_API='';` → впишите адрес воркера: `const ORDER_API='https://geza.<имя>.workers.dev';`
- найдите `const TG={token:'…', chat:'…'};` → очистите: `const TG={token:'', chat:''};`
  (теперь токен хранится только на сервере).

## 4. Владелец
Открывает ссылку со страницы /setup (`https://t.me/<бот>?start=<PASSWORD>`) → «Старт».
Подключить можно нескольких людей. Отключиться — `/stop`.

## Команды бота
- `/menu` — панель управления (кнопки)
- `/today`, `/tomorrow` — записи на сегодня / завтра, с кнопками отмены
- `/close` — закрыть запись (можно с текстом: `/close Отпуск до 20 октября`), `/open` — открыть
- `/block` — убрать / вернуть время на любой день (или весь день целиком)
- `/price` — изменить цену услуги (цена «от», для Apple; для других брендов сайт пересчитывает сам)

Сайт подхватывает изменения в течение минуты. Время — московское (Санкт-Петербург).
